# Додаткові залежності проєкту

У проєкт було додано наступну бібліотеку:

* **lucide-react**: Використовується для відображення лаконічних SVG-іконок (наприклад, іконка-хрестик `X` для закриття модального вікна). Це сучасний, легкий інструмент, що чудово інтегрується з TailwindCSS і не обтяжує фінальну збірку додатку.
